# 💜 Barney and Friends

## About the Show
**Barney and Friends** is a fun and educational children's TV show about a friendly purple dinosaur named Barney.

Barney teaches children about:
- Friendship ❤️
- Kindness 😊
- Sharing 🤝
- Respect 💜
- Love and happiness 🌈

## Main Characters
1. **Barney** – A friendly purple dinosaur.
2. **Baby Bop** – A cute green dinosaur.
3. **B.J.** – Barney's playful friend.
4. **The Children** – Barney's friends and students.
